 
# 🖼️ Responsive Image Gallery

A modern, responsive **Image Gallery** built using **HTML**, **CSS**, and **JavaScript**. This project was developed as part of the **CodeAlpha Frontend Development Internship (Task 1)**.

The gallery allows users to browse images in a clean grid layout, view images in a fullscreen lightbox, and navigate between images using on-screen controls or keyboard shortcuts.

---

## 🚀 Features

- 🖼️ Responsive Image Grid
- 🔍 Click-to-Open Lightbox
- ⬅️➡️ Previous & Next Navigation
- ❌ Close Lightbox
- ⌨️ Keyboard Navigation Support
- 📱 Mobile-Friendly Design
- ✨ Smooth Hover & Transition Effects
- 🎨 Modern User Interface

---

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/image-gallery.git
```

2. Open the project folder.

```bash
cd image-gallery
```

3. Open `index.html` in your preferred web browser.

No installation or additional dependencies are required.
